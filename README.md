# character-lipsync

Процедурный 2D-липсинк для статичных персонажей под аудиодорожку.

Превращает набор из 1–4 статичных PNG-изображений персонажа с закрытым ртом и аудиофайл в видео, где персонаж синхронно говорит в такт речи, моргает/дышит и меняет позы.

Для работы не требуются нейросети, видеокарты и сторонние платные API: анимация строится на геометрическом варпе челюсти (displacement warp), процедурной отрисовке полости рта и анализе локальной огибающей громкости аудио.

Поддерживается вывод в прозрачный `.mov` (Apple ProRes 4444 с альфа-каналом) для встраивания в монтажные программы (After Effects, Premiere Pro, Final Cut, DaVinci Resolve, Remotion) или в стандартный `.mp4` с заданным фоновым цветом или фоновой картинкой.

---

## Возможности

- Анимация речи без артефактов нейросетей: лицо не деформируется, уголки рта зафиксированы на месте, челюсть опускается плавно.
- Процедурная отрисовка полости рта: полость нужного оттенка, зубы, язык и контур под стиль иллюстрации.
- Адаптивная огибающая звука: сравнение громкости кадра со средним значением за 0.4 секунды. Слоги четко открывают рот, спады закрывают.
- Шумовой гейт (gate_db): полное закрытие рта в паузах и микропаузах между словами.
- Поддержка смены поз по расписанию (schedule) с пружинящим отскоком (pop) и синусоидальным покачиванием (idle breathing).
- Экспорт чистой огибающей рта в формате JSON (--envelope) для рендера в других графических пайплайнах.
- Низкие требования к ресурсам: оптимизированная покадровая обработка и безопасное кодирование через ffmpeg без переполнения памяти.

---

## Принцип работы

1. **Варп челюсти (Displacement Warp).** Пиксели ниже линии смыкания губ смещаются вниз пропорционально коэффициенту открытия h. Максимальный сдвиг приходится на область под губой с мягким затуханием к подбородку (около 0.95 ширины рта) и косинусным затуханием по краям к уголкам. Уголки остаются неподвижными, геометрия лица не нарушается.
2. **Процедурная полость.** В образовавшемся зазоре рисуются внутренняя полость рта темного оттенка, контур, полоска верхних зубов и язык.
3. **Кэш 9 состояний.** Для каждой позы заранее генерируются промежуточные уровни открытия (по умолчанию 9 состояний), после чего нужный кадр берется из кэша по значению огибающей.
4. **Анализ звука.** Вычисляется RMS-энергия с сопоставлением скользящему среднему окну. В отличие от наивного RMS, рот не «залипает» в полуоткрытом положении на гласных и плавно смыкается на согласных и тишине.
5. **Смена поз.** Переключение между позами происходит по временным меткам с интерполяцией масштаба (отскок 0.9 -> 1.0) и фоновым дыханием персонажа.

## Требования

- Python 3.9 или выше
- ffmpeg, установленный в системе и доступный в PATH (или по пути `/opt/homebrew/bin/ffmpeg`)
- Зависимости Python: `numpy`, `opencv-python`, `Pillow`

Опционально: `librosa` (для ускоренной загрузки аудио; при ее отсутствии загрузка автоматически выполняется через ffmpeg).

## Быстрый старт

### 1. Определение координат рта (калибровка)

Для каждой позы необходимо узнать координаты левого и правого уголков темной линии между губами.

Вызов сетки с разметкой пикселей:
```bash
python3 scripts/calibrate.py grid pose1.png --out grid1.png --box 450 470 720 600 --step 10
```
Параметр `--box x0 y0 x1 y1` задает область лица, `--step` — шаг сетки в пикселях.

Проверка разметки и превью открытия:
```bash
python3 scripts/calibrate.py check pose1.png --lips 505 549 650 534 --out check1.png
```
Команда сохранит файл `check1.png`:
- В первом ряду будет исходная поза с красными точками на уголках рта.
- В последующих — тест раскрытия на 0%, 33%, 66% и 100%. Красные точки должны лежать ровно на краях линии между сомкнутыми губами.

### 2. Учет кривизны линии губ (curve)

Если на рисунке рот имеет заметный изгиб (дугу), для идеального прилегания полости рта можно снять коэффициенты параболы `y = c0 + c1*dx + c2*dx^2`:

```python
import numpy as np
from PIL import Image

lum = np.array(Image.open('pose1.png').convert('RGB')).astype(float).mean(axis=2)
# Точки самого темного пикселя в коридоре между уголками:
x0, y0, x1, y1 = 505, 549, 650, 534
cx = (x0 + x1) / 2.0
pts = [(x, y0 - 30 + int(np.argmin(lum[y0 - 30:y0 + 30, x]))) for x in range(x0 + 8, x1 - 7)]
c = np.polyfit([p[0] - cx for p in pts], [p[1] for p in pts], 2)
# Итоговый массив: [c0, c1, c2]
curve = [float(c[2]), float(c[1]), float(c[0])]
print(curve)
```

### 3. Настройка config.json

Создайте файл конфигурации (шаблон доступен в `config.example.json`):

```json
{
  "audio": "voice.wav",
  "out": "talking.mov",
  "fps": 30,
  "width": 1080,
  "height": 1920,
  "background": "transparent",
  "poses": {
    "1": {
      "image": "pose1.png",
      "lips": [[505, 549], [650, 534]],
      "curve": [534.9, -0.1073, 0.00169]
    },
    "2": {
      "image": "pose2.png",
      "lips": [[640, 520], [785, 505]],
      "curve": [504.4, -0.0909, 0.00201]
    }
  },
  "schedule": [
    [0.0, "1"],
    [5.15, "2"],
    [10.9, "1"]
  ],
  "character": {
    "scale": 0.57,
    "anchor": "bottom-right",
    "offset": [80, 40]
  },
  "hmax_ratio": 0.186,
  "levels": 9,
  "threshold": 0.12,
  "gate_db": -40.0,
  "bob": true,
  "pop": true
}
```

### 4. Рендер

Проверка отдельных секунд без полного рендера:
```bash
python3 scripts/lipsync.py config.json --preview 1.0 3.5 8.0
```

Полный рендер видео:
```bash
python3 scripts/lipsync.py config.json
```

Экспорт только значений открытия рта по кадрам (0.0 .. 1.0):
```bash
python3 scripts/lipsync.py config.json --envelope envelope.json
```

## Описание параметров конфигурации

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `audio` | string | обязательно | Путь к аудиофайлу (WAV, MP3, AAC и др.). |
| `out` | string | обязательно | Путь к итоговому файлу (`.mov` для прозрачности или `.mp4`). |
| `fps` | int | 30 | Частота кадров видео. |
| `width`, `height` | int | 1080, 1920 | Разрешение результирующего холста. |
| `background` | string | `"transparent"` | `"transparent"` (ProRes 4444 с альфой), hex-код вида `"#ECEAE5"` или путь к файлу изображения фона. |
| `poses` | dict | обязательно | Словарь поз персонажа с координатами уголков рта `lips` и кривизной `curve`. |
| `schedule` | list | `[[0, "1"]]` | Расписание смены поз: список пар `[секунда, id_позы]`. |
| `character.scale` | float | 1.0 | Масштаб персонажа относительно исходного размера. |
| `character.anchor` | string | `"bottom-right"` | Точка привязки персонажа на холсте: `bottom-right`, `bottom-left` или `center`. |
| `character.offset` | [int, int] | `[0, 0]` | Смещение в пикселях [X, Y] от точки привязки. |
| `hmax_ratio` | float | 0.186 | Максимальное раскрытие рта относительно расстояния между уголками губ. |
| `levels` | int | 9 | Количество промежуточных фаз открытия рта в кэше. |
| `threshold` | float | 0.12 | Порог шума огибающей: все значения ниже считаются закрытым ртом. |
| `gate_db` | float | -40.0 | Абсолютный шумовой гейт в децибелах для отсечения дыхания и фона в паузах. |
| `bob` | bool | true | Включение покачивания персонажа («дыхание» в кадре). |
| `pop` | bool | true | Включение пружинящего эффекта при переключении позы. |

## Требования к исходным изображениям

- Формат: PNG с прозрачным фоном.
- Персонаж: единый стиль отрисовки для всех поз, рот сомкнут (закрыт).
- Линия смыкания губ должна быть четкой, не перекрываться усами, бородой или посторонними предметами.
- Положение лица: анфас или поворот на 3/4 (наклон головы не более 20 градусов).
- Разрешение: рекомендуемая ширина рта на исходном изображении не менее 100 пикселей.
- Одинаковые границы холста для всех файлов поз одного персонажа.

Пример промпта для генерации поз персонажа через графические нейросети:

```text
Тот же персонаж, что на референсе: [возраст, стиль, прическа, одежда].
2D cartoon illustration, thick clean outlines, flat/soft shading, waist-up portrait, transparent background.
Поза: [указывает пальцем вверх / держит подбородок / жест рукой].
Рот ЗАКРЫТ, губы сомкнуты, легкая улыбка, взгляд в камеру или 3/4.
Строго сохранять черты лица, прическу, пропорции и одежду.
```
